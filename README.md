# Python Practice Set 🐍

A collection of beginner-friendly Python mini-projects built while learning core programming concepts — functions, file handling, and Object-Oriented Programming (OOP).

Each project is written from scratch with simple, clear logic. Great for anyone learning Python, brushing up on fundamentals, or looking for hands-on practice problems.

---

## 📂 Projects

### Functions & Logic
- **Restaurant Bill Splitter** – calculates subtotal, service charge, splits the bill, and adds a tip using functions.
- **Movie Ticket Pricing** – calculates ticket prices based on age groups using conditionals and loops.
- **Simple Grading System** – converts numeric scores into letter grades and calculates class average.
- **Password Strength Checker** – validates password strength (length, digits, uppercase letters).

### File Handling
- **To-Do List Saver** – add and view tasks stored in a text file, with a menu-driven loop.
- **Expense Tracker** – logs expenses to a file and calculates the total amount spent.
- **Simple Contact Book** – add, view, search, and delete contacts stored in a text file.

### Object-Oriented Programming (OOP)
- **Task Calculator** – a `Calculator` class demonstrating basic OOP with add/subtract/multiply/divide.
- **Bank Account Class** – a `BankAccount` class with deposit, withdraw, and balance tracking.
- **Contact Book (OOP version)** – the contact book rebuilt using a `Contact` class instead of raw file parsing.

---

## 🎯 Concepts Covered
- Functions, parameters, and return values
- Conditionals (`if` / `elif` / `else`) and loops
- File handling (`read`, `write`, `append`)
- Menu-driven programs using `while True` loops
- Object-Oriented Programming: classes, objects, `self`, constructors (`__init__`), and instance variables

---

## 🚀 How to Use
1. Clone or download the repo
2. Open `practice.py` (or individual project files, if split)
3. Run with Python 3:
   ```bash
   python practice.py
   ```
4. Follow the on-screen menu prompts for each project
